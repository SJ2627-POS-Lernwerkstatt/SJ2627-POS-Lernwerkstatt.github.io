# Datenschutz

Diese Seite speichert **keine Daten auf einem Server**. Es gibt keine Anmeldung, keine Cookies und keine Statistik- oder Tracking-Dienste.

- **Dein Fortschritt** (gelesene Einheiten, Ergebnisse deiner Übungsrunden, Einstellungen) wird nur im Speicher deines Browsers (`localStorage`) abgelegt. Er verlässt deinen Computer nur, wenn du ihn selbst als Datei exportierst.
- **Schriften, Diagramme und Skripte** werden direkt von dieser Seite geladen. Es werden keine Anfragen an andere Anbieter gestellt.
- **Gehostet** wird die Seite bei GitHub Pages. GitHub verarbeitet dabei, wie jeder Webserver, technische Zugriffsdaten (z. B. IP-Adresse) – siehe [GitHub Privacy Statement](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).
- **Programmieraufgaben** werden über Classroom50 und GitHub abgegeben. Dafür gelten die Bedingungen dieser Dienste und die Vereinbarungen deiner Schule.

Du kannst deinen Fortschritt jederzeit löschen, indem du die Websitedaten dieser Seite in deinem Browser entfernst.
